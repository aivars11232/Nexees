SPECIFICATION:
    ID: specification.arch_subsystems
    NAME: "Subsystems, module ownership and shared versus client-specific code"
    VERSION: "0.5.0"
    KIND: kind.part.data
    DESCRIPTION: "The 24 subsystems of Nexees and the module slots each one owns. Every file of the product layout (apps, core, platform, integrations, assets, config, packaging, scripts and the manual sources) belongs to exactly one slot of one subsystem, and every planned test file is attributed to the subsystem it primarily proves. Shared code is the shared_core layer, which runs unchanged in both local hosts; client-specific code is confined to the client_ui and platform_adapter layers and to the Desktop-only IDE integration."
