        topic: "Imported content"
        finding: "Imported files enter as untrusted content in app-private staging that belongs to the target host (ST-IMPORT), and touch no live workspace until the user confirms the preview. No import path writes grants, approvals, settings or secrets, starts an agent, or changes another workspace's rules or the user's focus. The boundary holds."

    ID: data.arch_rv_late_replies
    TYPE: OBJECT[REF(type.arch_review)]
    VALUE:
        review_id: "RV-02"
        gate: "T002.VERIFY.01"
        topic: "Late replies"
        finding: "Five kinds of late arrival were traced. A reply or tool request from an older model generation is rejected by the execution fence before dispatch. A tool result that arrives after cancellation or timeout is recorded in the operation journal, and a non-idempotent effect with unknown outcome is reconciled, not replayed. A late remote acknowledgment reconciles the sender's pending record by request ID without executing again, and an expired request is refused at admission. A delayed sync change meets a base-revision check and becomes a conflict, never an overwrite. A late approval is revalidated against epoch, expiry, lock state and target before use. The boundary holds."
        references: ["SS-AGENT", "SS-REMOTE", "SS-SYNC", "ST-JOURNAL", "ST-REMOTE-REQUEST", "ST-SYNC", "ST-AUTHORITY", "IF-REMOTE", "FL-MODEL-SWITCH", "FD-TOOL"]
        result: "holds"
